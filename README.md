# 🌍 HobbiGo - AI Journey & Experience Marketplace 

![HobbiGo Banner](https://images.pexels.com/photos/2166553/pexels-photo-2166553.jpeg?auto=compress&cs=tinysrgb&w=1200)

**HobbiGo** is a next-generation travel platform that combines the power of Artificial Intelligence with a comprehensive global marketplace. From planning the perfect itinerary to booking flights, hotels, and local experiences — everything is in one place.

## 🚀 Live Demo 
Experience the prototype here: 
👉 **[https://hobbigo.github.io/hobbigo/](https://hobbigo.github.io/hobbigo/)**

## ✨ Key Features
*   **🤖 AI Trip Planner:** Generates personalized itineraries, routes, and estimated budgets based on user preferences.
*   **🏨 Global Marketplace:** Seamlessly discover and book hotels, flights, transport, and restaurants with realistic live-data UI.
*   **🏢 Corporate & Event Builder:** A dedicated tool for businesses to plan retreats, meetings, and team-building packages.
*   **🛒 Smart Booking System:** Add multiple experiences to a single cart and checkout as one complete package.
*   **💬 AI Assistant:** A floating chatbot ready to help users navigate the platform.

## 🛠️ Tech Stack
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (Mobile-First Responsive)
*   **Backend Proxy:** Cloudflare Workers (For future API integrations)
*   **Icons & Fonts:** FontAwesome, Google Fonts (Poppins)
*   **Deployment:** GitHub Pages
