🏗️ HobbiGo Real Data Architecture

1

👤 User Layer

Customer searches destination, dates, people, budget, interests, event type and travel preferences.

2

🧠 AI Engine

AI analyzes user intent and determines destination, itinerary, vendors, route and package recommendations.

3

🔌 API Gateway

Central gateway connects external APIs and protects the frontend from provider differences.

4

🗂️ Data Normalizer

Different provider formats are converted into one HobbiGo standardized product structure.

5

📍 Location Engine

GPS, latitude, longitude, geocoding, distance, ETA, traffic and route optimization.

6

🛒 Marketplace

Hotels, flights, restaurants, venues, transport, activities, attractions and global HobbiGo partners.

7

📦 Package Engine

Combines products into economy, comfort, premium and exclusive packages.

8

💳 Booking & Payment

Inventory confirmation, reservation, payment, cancellation and refund workflows.

9

🌍 Live Trip

Real-time trip monitoring, GPS, traffic changes, itinerary updates and AI re-optimization.


🗃️ Standard HobbiGo Product Data Model

Every external product is converted into this normalized structure before entering the HobbiGo marketplace.

product_id Unique product identifier
partner_id HobbiGo partner identifier
country Destination country
city Destination city
category Hotel / Flight / Activity etc.
name Product name
latitude GPS latitude
longitude GPS longitude
price Base product price
currency IDR / USD / EUR etc.
availability Real inventory status
rating Customer / provider rating
opening_hours Operating schedule
images Product image collection
booking_url Reservation endpoint
api_source Original provider

🔐 Production Architecture Security

🔑 API Keys Keys should be stored in backend environment variables, not inside public index.html.
🛡️ API Gateway External providers are accessed through controlled backend endpoints.
👤 Authentication Customer and partner requests should use authenticated sessions/tokens.
📊 Logging API requests, errors, booking events and provider responses can be monitored.
